# Kai Yi Ji — Portfolio

Personal portfolio site, built with React and Vite and deployed to GitHub Pages at
https://kaiji123.github.io/portfolio/.

The previous version of the site is kept on the `archive` branch.

## Editing content

All text — experience, education, research, projects, skills — lives in
[`src/data.js`](src/data.js). Update that file; no component changes needed.
Replace `src/assets/profile.jpg` to change the photo.

## Commands

```bash
npm install       # once
npm run dev       # local dev server
npm run build     # production build into dist/
npm run deploy    # build and publish dist/ to the gh-pages branch
```
